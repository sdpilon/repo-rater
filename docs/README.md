# docs/

Development-process records, not user documentation — see `README.md` for
how to use the app and `ARCHITECTURE.md` for how it's built. Nothing here
is required reading to self-host or contribute.

- **`specs/`** — pre-implementation design docs for specific features.
  Some describe code that's still live; treat each as a snapshot of the
  thinking at the time it was written, not a current-state reference.
- **`postmortems/`** — retrospectives on how a piece of work actually went,
  written after the fact. Dated historical records, left unedited.
- **`retired/`** — plans for code that's since been deleted from the repo.
  Not runnable or current; safe to skip entirely.
